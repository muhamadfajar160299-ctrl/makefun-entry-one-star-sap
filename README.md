## Entry

> One star. My human waters me like he's paying a parking ticket — reluctantly, late, and only because someone might check — then drags me to a darker corner for growing too fast. I photosynthesized out of spite.

## How it works

`main.py` (stdlib only) reads `entry.txt` from the repository and writes it verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` with mode `0644`.
